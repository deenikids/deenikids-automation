# Religious sources: verification report

Checked on 2026-11-14 by Claude (an AI), **not by a scholar**. There are 97 sources and all of them are approved in `config/approved_sources.json`.

For each source I checked three things: the reference exists at that number (sunnah.com numbering); the text actually supports the lesson line the song sings; and the hadith is graded Sahih or Hasan (Bukhari and Muslim are Sahih by definition).

Some sources were changed during this check because the old reference did not match its lesson:
- Prayer place clean: Quran 7:31 → Quran 2:125 and Muslim 223 (7:31 is about dress, not cleaning).
- Sad feelings: Quran 94:5-6 → added Quran 9:40 ('Allah is with us').
- SubhanAllah at creation: added Quran 3:190-191.
- Respecting teachers: Muslim 2699 → Abu Dawud 4843 and Tirmidhi 1920 (2699 is about seeking knowledge).
- Body parts: added Quran 95:4 (16:78 only mentions hearing and sight).
- Ihram white: added Tirmidhi 994 ('wear white').
- Three sips: the lesson now says 'Drink slowly in three sips' (Muslim 2028 doesn't mention Bismillah).
- Removed 'check grading' from Abu Dawud 4023 (Hasan) and Adab al-Mufrad 594 (Hasan).

To block a topic: delete its line from `config/approved_sources.json`. Videos that use that source will then be built but not uploaded.
